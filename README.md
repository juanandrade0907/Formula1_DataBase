# 🏎️ Trabalho Fórmula 1 — Banco de Dados SQL

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso de **Ciência da Computação**, com o objetivo de aplicar conceitos de modelagem e manipulação de bancos de dados relacionais utilizando SQL.

O trabalho consiste na criação e estruturação de um banco de dados relacionado à Fórmula 1, contemplando informações sobre países, equipes, pilotos, corridas e participantes.

## 🛠️ Tecnologias Utilizadas

- **MySQL** — Sistema de gerenciamento de banco de dados.
- **SQL** — Linguagem utilizada para definição, manipulação e consulta de dados.

## 🗄️ Estrutura do Banco de Dados

O banco de dados é composto pelas seguintes tabelas:

- `pais` — Informações dos países.
- `equipes` — Dados das equipes de Fórmula 1.
- `pilotos` — Informações dos pilotos.
- `corrida` — Dados das corridas e Grandes Prêmios.
- `participantes` — Relacionamento entre pilotos e corridas.

## 📚 Conceitos Aplicados

Durante o desenvolvimento do projeto, foram trabalhados conceitos fundamentais de SQL:

- Criação e estruturação de tabelas (`CREATE TABLE`).
- Definição de chaves primárias (PK) e estrangeiras (FK).
- Inserção e atualização de registros (`INSERT` e `UPDATE`).
- Alteração da estrutura das tabelas (`ALTER TABLE`).
- Consultas e filtragem de dados (`SELECT` e `WHERE`).
- Ordenação e organização de resultados (`ORDER BY`).
- Relacionamento entre tabelas.

## 🎯 Objetivo Acadêmico

Consolidar os conhecimentos introdutórios em bancos de dados relacionais, desenvolvendo habilidades práticas na utilização do MySQL e na linguagem SQL.
